# Week 8 Lab – HTML Parsing Practice

## Overview
This project demonstrates the use of BeautifulSoup for parsing HTML and extracting data.

## Features
- Extracts page title
- Extracts list items
- Extracts links
- Uses CSS selectors
- Simulates polite scraping with delays

## How to Run
1. Install BeautifulSoup:
   pip install beautifulsoup4

2. Run the script:
   python scraper.py

## Files
- scraper.py – main Python script
- sample.html – test HTML file
- reflection.txt – answers to lab questions
